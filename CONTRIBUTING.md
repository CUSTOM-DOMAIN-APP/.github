# Contributing

Thanks for helping improve the CustomDomain™ guides and documentation.

- **Docs** live in [CUSTOM-DOMAIN-APP/docs](https://github.com/CUSTOM-DOMAIN-APP/docs) (`content/`). Docs merged to that repository's `main` go live on [docs.customdomain.ai](https://docs.customdomain.ai/docs) with the next product deploy, which rebuilds the docs site from `main`.
- **Guide repos** (`connect-domain-for-*`) welcome corrections, additional provider notes, and clearer examples.
- **awesome-custom-domains** accepts tools directly relevant to connecting customer-owned domains to platforms: one line per tool, alphabetical within its section, factual descriptions.

House style: plain language, short paragraphs, tables where they clarify, no em dashes or en dashes, American English, real DNS/TLS facts only (no invented numbers). Write the product name as CustomDomain™ (one word, capital C and D, with the ™); "custom domain" in lowercase is the generic thing a customer connects. Typo PRs are always welcome.
